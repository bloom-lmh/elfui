# v0.1.0-beta.18 Hardening Plan

Date: 2026-07-29

## Goal

Close the confirmed runtime, compiler, architecture, performance, and documentation gaps found in the beta.18 audit. Correctness and lifecycle ownership take priority over preserving the current bundle figures; size budgets may grow modestly when the final measured output justifies it.

## Confirmed Issues

- `createInjectionKey()` aliases keys that share a description, including all unnamed keys.
- Teleport treats a `DocumentFragment` as a persistent mounted node, losing ownership of multi-root content after insertion.
- Suspense stops the newly created render scope immediately and its deferred compiler mount can escape component ownership.
- Transition does not own scopes created by later children and does not fully cancel pending animation work on disposal.
- TransitionGroup keeps stale plain item/index values for stable keys and lacks complete owner cleanup.
- A child deferred by its parent can remain permanently marked as mounted after disconnecting before setup.
- Offline dynamic-component code generation drops props, directives, and children that the runtime compiler preserves.
- ErrorBoundary cannot remove fragment children on retry.
- `element.ts` and `builtin.ts` form an avoidable ESM cycle through KeepAlive internals.
- Four packages declare unused direct `@elfui/shared` dependencies.
- Macro detection parses files more than once unnecessarily, and list same-key updates can trigger redundant reactive work.
- The template typecheck release gate currently scans zero macro fixtures.
- English and Chinese documentation contains stale bundle figures, omits `batch()`, and exposes a top-level Playground navigation item contrary to repository conventions.

## Implementation Phases

### 1. Runtime Ownership and Cleanup

- [x] Make user injection keys locally unique while retaining global symbols only for internal cross-runtime protocols.
- [x] Introduce a persistent node-range utility for rendering, moving, and removing single-node and fragment results.
- [x] Apply node-range ownership to Teleport and ErrorBoundary.
- [x] Repair Suspense render-scope replacement, source races, fragment cleanup, and owner disposal.
- [x] Give Transition each rendered child a detached scope and cancellable animation lifecycle.
- [x] Make TransitionGroup item/index inputs reactive, batch stable-key updates, and dispose every item/listener on owner teardown.
- [x] Reset deferred child scheduling state when disconnecting before setup.
- [x] Move KeepAlive protocol symbols to a dependency-neutral internal module and remove the runtime cycle.

### 2. Compiler Parity

- [x] Generate dynamic-component props, directives, events, refs, and children with the same semantics as runtime compilation.
- [x] Ensure delayed built-in work stays owned by the creating component scope.
- [x] Expand runtime/offline parity coverage for Dynamic Component, Teleport, Suspense, ErrorBoundary, and fragment/multi-root content.
- [x] Add a representative macro fixture so template typecheck scans at least one file.

### 3. Dependencies and Performance

- [x] Remove unused direct `@elfui/shared` package edges and regenerate the lockfile.
- [x] Add a cheap macro-import pre-filter. Parsed-source reuse remains grouped with the shared-lowering follow-up because the current public compile boundary does not accept an AST.
- [x] Batch list item/index updates and verify the same-key browser benchmark.
- [x] Evaluate a reactivity state split against the retained `useRef` dependency graph. Do not split: object refs synchronously require the object/array/collection proxy path, so moving files would not reduce the measured 2.64 KB gzip import.
- [x] Record shared compiler IR/lowering, parsed-source reuse, and incremental template typechecking as follow-up architecture work; completing them here would broaden beta.18 release risk.

### 4. Documentation

- [x] Document `batch()` and automatic event batching in English and Chinese API/guide pages.
- [x] Replace stale bundle figures with final post-fix measurements and distinguish the real-app fixture from aggregate package facades.
- [x] Remove Playground from the top navigation to restore the documented Home/API/language-only convention.
- [x] Keep `@elfui/core` and `@elfui/vite-plugin` aligned at beta.18.
