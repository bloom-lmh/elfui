# v0.1.0-beta.21 Incremental Template Diagnostics Plan

Date: 2026-07-29

## Goal

Reduce repeated TypeScript program and standard-library construction during macro template type
checking while preserving exact compiler diagnostics, generated code, metadata, and source maps.

## Baseline

The corrected Language Tools benchmark over 117 real ElfUI Kit macro files records 59,061.0 ms
cold diagnostics with npm compiler beta.20, including 58,945.3 ms in
`compileMacroComponent(..., { templateTypeCheck: true })`. The earlier lower attribution ran
outside the packaged TypeScript-library directory and is invalid.

## Work

- [x] Add a real Kit macro diagnostic benchmark with cold and second-pass totals.
- [x] Reuse a bounded TypeScript `Program` per compatible workspace/compiler-option key.
- [x] Limit diagnostic collection to the generated template source file.
- [x] Test source edits, imported-file isolation, macro-import isolation, and cache eviction.
- [x] Run compiler verification, size, transform benchmark, package-surface, and publish gates.
- [x] Record measured results and release/consumption status.

## Non-goals

- Changing template semantics or compiler protocol.
- Caching full `compileMacroComponent()` results.
- Retaining unbounded source text or one TypeScript program per component.
- Modifying runtime reconciliation or browser performance paths.

## Verification

- Direct compiler baseline: 73,321.5 ms cold and 78,396.9 ms second pass over 117 Kit files.
- Optimized compiler: 55,969.1 ms cold and 58,732.3 ms second pass, reducing the two passes by
  23.7% and 25.1%.
- Four beta.20 Kit diagnostics were confirmed to originate in imported files and were projected
  onto unrelated template entries solely because their line numbers matched. The optimized
  target-file diagnostic set is clean.
- Language Tools with local compiler source: 51,915.7 ms cold and 3.9 ms cached repeat, 12.1%
  below the corrected 59,061.0 ms npm beta.20 cold baseline.
- Focused compiler diagnostics tests: 3/3 passed.
- `pnpm verify`: 52 files and 618 tests passed with all compiler/API/build/static gates.
- Size, Chromium performance, external/host/runtime-copy integration, package-surface, and
  seven-package publish dry-run gates passed.
- A synchronized patch changeset is ready. Beta.21 npm publication and permanent Language Tools
  dependency consumption require a separate release action and are not part of this implementation
  commit.
